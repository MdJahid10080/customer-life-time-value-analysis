# Customer Lifetime Value Analysis

Customer Lifetime Value (CLV) Analysis using Python, RFM Analysis, and Random Forest Classifier. This project segments customers into value-based groups, identifies customer behaviour patterns, and provides business insights for customer retention and targeted marketing.

## 🚀 Live Deployment

**Streamlit App:** https://customer-lifetime-analysis-2zhwtz.v2.appdeploy.ai/

The interactive application allows users to:
- Analyze customer RFM values
- Predict customer segments
- Explore different customer profiles
- Run what-if RFM scenarios
- View model insights and feature importance
- Understand the five customer segments

## 🛠️ Technologies

- Python
- Pandas
- Scikit-learn
- Random Forest
- RFM Analysis
- Joblib
- Streamlit

## 📊 Project Scope

The application focuses on customer segmentation using historical Recency, Frequency, and Monetary (RFM) behaviour. It does not directly forecast a future monetary CLV amount.
